## Long-form (YouTube)

### A. Founder story (3–5 min)

Expand script #8:

1. Problem: smartphones too much, kid watches too expensive and tracked
2. Vision: home phone reborn — tap a face, only approved people
3. How it works: Mothership, Pods, Circles (30 sec plain English)
4. Privacy: no recording, decentralized, your server
5. Honest limits: no 911, no PSTN
6. CTA: TestFlight, trial, GitHub

**Thumbnail:** Kid on landline or speed dial UI + "Private Family Phone" text in Fraunces.

---

### B. Set up your Mothership (10 min)

Screen recording with VO:

1. Download from GitHub releases or HA add-on
2. First launch, DuckDNS or HTTPS URL
3. Create parent account, add kid line
4. Send invite to second family member
5. Optional: HT801 provisioning overview (link to docs)

**Chapters:** Install · HTTPS · First account · Invites · House phone
