Support

Help for families using PhoneHome on the web or the free iOS app.

Get connected

  1. Open your Mothership Use the HTTPS address of your family’s Mothership (private PhoneHome server).
  2. Or use the free iOS app Paste that address — a full invite / Grandma setup link works too.
  3. Sign in Use the username and password a parent created for you.
  4. Allow the microphone Required when you place or answer your first call.

Share links & tokens

  • /?join=… — one-tap join (family, friend, or co-parent)
  • /?gp=… — Grandma/Grandpa one-tap setup
  • /?invite=123456 — 6-digit invite code in a link

These links must use your Mothership’s public HTTPS URL (PUBLIC_BASE_URL). If the App URL in Mothership admin is wrong, ask the host parent to fix it.

iOS app (free)

  • Same softphone as the website, plus lock-screen Answer (CallKit) and Face ID
  • Parent → This phone → Change Mothership address if the server URL moves
  • Optional: turn off lock-screen Answer under the same screen

Common issues

  • Can’t connect — confirm the address starts with https:// and the Mothership is online
  • No mic — HTTPS is required; check site / app permissions
  • Invite didn’t work — ask for a fresh link; one-tap tokens expire after use
  • House phone offline — see Analog Phone in Parent settings (Download config for remote cousins)

Contact

Email support@example.com for host-license billing, setup help, or account questions. Include your device, iOS/browser version, and Mothership URL (not SIP passwords or call audio).

You can also file an issue on GitHub for reproducible bugs.
