PhoneHome Mothership — START HERE
==================================

macOS
-----
Easier: the same GitHub release has "PhoneHome-Mothership-*-macos.dmg" —
open it, drag PhoneHome Mothership to Applications, launch (UFO icon in
the menu bar). Preferences → DuckDNS subdomain + token → Test & apply.

Use this zip only if you prefer a Terminal install:

1. Unzip this folder (double-click the .zip from GitHub).
2. Open the folder "phonehome-mothership".
3. Double-click:  Install PhoneHome Mothership.command

   If macOS says it can't be opened:
   • Right-click the file → Open → Open again
   • Or: System Settings → Privacy & Security → Open Anyway

4. Enter DuckDNS subdomain + token (recommended), or skip for later.
5. Your browser opens http://127.0.0.1:8787 — use the setup code shown there.

Linux
-----
  cd phonehome-mothership
  ./install-mothership.sh

Windows
-------
  Right-click install-mothership.ps1 → Run with PowerShell
  (If blocked: Set-ExecutionPolicy -Scope Process Bypass)

Public hostname for phones
--------------------------
  Recommended: DuckDNS — https://www.duckdns.org
  Create a subdomain, put DUCKDNS_DOMAIN + DUCKDNS_TOKEN in
  ~/.phonehome/phonehome.env (Mac/Linux) or
  %USERPROFILE%\.phonehome\phonehome.env (Windows).
  Mothership updates DNS while running. Forward HTTPS (e.g. 8443)
  to this computer and terminate TLS (Caddy, etc.).

  Alternative (no port forward): cloudflared tunnel — see INSTALL.md.

More help: INSTALL.md in this folder.
